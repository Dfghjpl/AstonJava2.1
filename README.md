# MyHashMap

Учебная реализация хеш-таблицы на Java с разрешением коллизий через связные списки.

Поддерживает `null`-ключ, автоматическое расширение таблицы и основные операции: `put`, `get`, `remove`, `size`.

## Возможности

- Вставка, чтение и удаление по ключу
- Разрешение коллизий методом цепочек (singly linked list)
- Автоматический resize при превышении load factor
- Поддержка `null`-ключа
- Настраиваемая начальная ёмкость и load factor

## Как это работает

В основе — массив бакетов (`Node<K,V>[] table`), длина которого всегда степень двойки.

1. Из ключа вычисляется `hashCode()`, старшие биты подмешиваются в младшие (`h ^ (h >>> 16)`).
2. По хешу вычисляется индекс бакета: `(length - 1) & hash` — быстрый аналог `% length`.
3. Если в бакете уже есть элементы, они хранятся в виде связного списка.
4. При совпадении хеша и ключа значение обновляется, иначе новый узел добавляется в голову цепочки.
5. Когда `size` превышает `threshold = capacity * loadFactor`, таблица удваивается, а элементы перераспределяются.
